# CodeAlpha Task 4 - Banking System

## About the Project

This project is developed as part of the CodeAlpha C Programming Internship.

The Banking System is a menu-driven C program that manages basic banking operations using structures, functions, and file handling.

## Operations Performed

- Create Account
- Deposit
- Withdraw
- Balance Enquiry
- Exit

## Technologies Used

- C Programming
- Structures
- Functions
- File Handling

## How to Run

Compile:

gcc banking.c -o banking

Run:

./banking

## Account Details

The program stores:

- Account Number
- Name
- Balance
